Voice Arranger の使いかた

別々に録音した声をそろえて、長い間を詰め、音量を整えるツールです。

はじめに

  • Chrome か Edge で開いてください（Mac・Windows どちらでも使えます）。Safari では保存がうまくいかないことがあります。
  • インストールは不要です。音声は自分の PC の中だけで処理され、外部には送られません。
  • 1時間 × 3人ぶんで、メモリを 1〜2GB ほど使います。ほかの重いアプリは閉じておくと安心です。
ツールを開く →

録音するときのお願い

  1. 各自が自分の声を手元で録音します（iPhone のボイスメモなどで OK）。通話はイヤホンで聞くと、ほかの人の声が混ざりにくくなります。
  2. iPhone のボイスメモは、設定の「音質」を「圧縮」にしてください（「ロスレス」だと読み込めません）。
  3. 録音の開始・終了のタイミングはそろっていなくて大丈夫です。ツールが会話から自動で合わせます。
  4. 録音したファイルを、編集する人に送ります（AirDrop、Google ドライブなど）。

編集の手順

画面上の 4 つの手順を、左から順に進めます。

1 音声を入れる

  • 全員の録音ファイルを、画面にまとめてドラッグします（または「ファイルを選ぶ」）。
  • 必要なら話者の名前を直して、「自動で整える」を押します。数十秒〜数分かかります。

2 聞いて直す

  • 「▶ 再生」で聞いてみます。スペース でも再生 / 停止できます。
  • 間の詰め方は「控えめ / ふつう / しっかり」から選べます。
  • 切りたい所は、波形の上をなぞって選び「切って詰める」（または Delete）。
  • 灰色の帯（詰める間）をクリックすると「切らずに残す」にできます。
  • まちがえたら「↶ 元に戻す」（Ctrl＋Z、Mac は ⌘＋Z）。
  • 声がずれて聞こえるときは「声のタイミングがずれているとき」を開いて、開始位置を少しずつ動かします。
直した内容はブラウザに自動で保存されます。途中で閉じても、同じ音声を入れ直すと「復元する」で続きからできます。

3 「えー」を取る（やらなくても OK）

  • 「文字起こしを始める」を押します。初回だけ、文字起こしのデータ（約 320MB）をダウンロードします。Wi-Fi で行ってください。
  • 色の付いた言葉が「えー」などの候補です。 橙＝えー・あー（最初から「切る」）、 紫＝あの・その（最初は「残す」）。
  • 候補をクリックすると前後が流れます。「切る / 残す」を選んで「次 →」。← → で移動、Enter で切り替えもできます。
  • 自動の判断は「提案」です。聞いてみて、残したいものは残してください。
文字起こしの速さは PC によって大きく変わります。古い PC では時間がかかることがあります。

4 保存する

  • ファイル名を決めて「保存する」→ 保存先のフォルダを選びます。
  • ブラウザが「フォルダへのアクセスを許可しますか？」と聞いてきたら「許可」を選びます。

できあがるファイル

ファイル使いみち
名前_1_話者名.wav など話者ごとの音声。GarageBand などで並べて仕上げるとき用
名前_mix.wav全員を混ぜた完成版。このまま配信にも使えます
名前_transcript.txt / .srt文字起こし（手順 3 をしたときだけ）。.srt は字幕用
そのほか（.csv / .json など）カットの記録です。ふだんは使わなくて大丈夫です

GarageBand で仕上げる

  1. 話者ごとの WAV を、それぞれ別のトラックに入れます。
  2. どれも先頭（1小節目の頭）にぴったり置きます。これだけでタイミングがそろいます。
  3. iPhone 版では、曲の長さ（セクション）を「自動」にし、取り込んだ音声の「テンポに合わせる」をオフにしてください。

困ったとき

ファイルを入れても読み込めない
ボイスメモの「ロスレス」で録音したファイルは読めません。「圧縮」で録り直すか、ほかのアプリで m4a / wav に変換してください。
声のタイミングが合っていない
手順 2 の「声のタイミングがずれているとき」で、開始位置を ±0.1 秒ずつ動かして合わせます。会話が短い（数分）と自動で合わせにくくなります。
途中で止まった・画面が固まった
メモリ不足のことがあります。ほかのタブやアプリを閉じて、ページを再読み込みしてください。直した内容は「復元する」で戻せます。
保存先を選ぶ画面が出ない
Chrome か Edge で開いているか確認してください。
うまくいかないときに作者へ伝えること
使ったブラウザ、録音の長さと人数、画面のいちばん下の「処理ログ」を開いた中身をコピーして送ってください。
